# Product Specification - Civis Italia

## User Flow Principale (3 passi)
1. Fotografa / Carica documento
2. Attendi elaborazione (target < 10 secondi)
3. Leggi spiegazione chiara + azioni

## Output AI per ogni documento
- Riassunto
- Cosa significa (traduzione dal burocratese)
- Cosa devi fare (checklist)
- Entro quando (scadenze)
- Quanto devi pagare
- Chi contattare (numeri e siti ufficiali)
- Documenti necessari
- Priorità (Alta / Media / Bassa)
- Tempo stimato

## Calendario Automatico
ISEE, 730, IMU, TARI, bollo auto, revisione, patente, carta d'identità, passaporto, assicurazione, bollette, SPID, PEC, firma digitale, permessi, certificati.
